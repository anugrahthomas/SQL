SQL Commands:

1. DDL (Data Definition Language):
- CREATE: used to create a new database, table, or other database objects.
- ALTER: used to modify an existing database object, such as adding or dropping columns in a table.
- DROP: used to delete an existing database object, such as a table or database.
- TRUNCATE: used to remove all records from a table, but not the table itself
- COMMENT: used to add comments to database objects, such as tables or columns, for documentation purposes.
- RENAME: used to change the name of an existing database object, such as a table or column.

2. DML (Data Manipulation Language):
- INSERT: used to add new records to a table.
- UPDATE: used to modify existing records in a table.
- DELETE: used to remove existing records from a table.

3. DQL (Data Query Language):
- SELECT: used to retrieve data from one or more tables in a database.
- FROM: used to specify the table(s) from which to retrieve data in a SELECT statement.
- WHERE: used to filter records based on specified conditions in a SELECT statement.
- GROUP BY: used to group records based on specified columns in a SELECT statement.
- HAVING: used to filter groups based on specified conditions in a SELECT statement.
- ORDER BY: used to sort records based on specified columns in a SELECT statement.
- DISTINCT: used to retrieve unique records from a table in a SELECT statement.
- LIMIT: used to limit the number of records returned in a SELECT statement.

4. DCL (Data Control Language):
- GRANT: used to give users access privileges to database objects.
- REVOKE: used to remove access privileges from users for database objects.

5. TCL (Transaction Control Language):
- BEGIN TRANSACTION: used to start a new transaction.
- COMMIT: used to save all changes made in the current transaction to the database.
- ROLLBACK: used to undo all changes made in the current transaction and revert the database to its previous state.
- SAVEPOINT: used to set a point within a transaction to which you can later roll back.

--- Constraints:
Constraint	    Description
PRIMARY KEY	    Uniquely identifies each record in a table (UNIQUE + NOT NULL)
FOREIGN KEY	    Ensures referential integrity between two tables
UNIQUE	        Ensures that all values in a column are unique
NOT NULL	    Ensures that a column cannot have a NULL value
CHECK	        Ensures that all values in a column satisfy a specific condition
DEFAULT	        Provides a default value for a column when no value is specified

AUTO_INCREMENT/IDENTITY	Automatically generates a unique value for a column when a new record is inserted (depending on the database system, this may be implemented differently, e.g., AUTO_INCREMENT in MySQL, IDENTITY in SQL Server, or SERIAL in PostgreSQL).
eg: CREATE TABLE employees (
    id              INT             PRIMARY KEY,
    name            VARCHAR(50)     NOT NULL,
    age             INT             CHECK (age >= 18),
    department_id   INT             DEFAULT 1,
    FOREIGN KEY (department_id) REFERENCES departments(id)
);

--- HAVING vs WHERE:
-- HAVING : it filters grouped records
- WHERE : it filters individual records before grouping
FROM
  ↓
WHERE
  ↓
GROUP BY
  ↓
HAVING
  ↓
SELECT
  ↓
ORDER BY
+---------+------------------+------------------+
|Clause	  | Filters	         |  Think           |
+---------+------------------+------------------+
|WHERE	  | Individual rows	 |  Before grouping |
|GROUP BY |	Creates groups	 |  Make buckets    |
|HAVING	  | Groups	         |  After grouping  |
+---------+------------------+------------------+


Type Casting in SQL:
- converting a value from one data type to another.
- can be done using the CAST() or CONVERT() functions, depending on the database system
SELECT CAST('123' AS INTEGER);
